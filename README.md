# Loan Approval Prediction Using Machine Learning

This project is a machine learning pipeline designed to predict loan approvals based on applicant data. Built with Python, the pipeline utilizes libraries such as Pandas, Scikit-learn, and Plotly to process data, train predictive models, and create interactive visualizations for data analysis.

Features:

1. Data Preprocessing:

    1. Handles missing values, feature encoding, and scaling for optimal model performance.

2. Predictive Modeling:

    1. Utilizes Scikit-learn to train and evaluate models for predicting loan approvals.

3. Interactive Visualizations:

    1. Leverages Plotly to create dynamic charts for analyzing key features, including applicant income, loan amount, and credit history.

4. Feature Importance Analysis:

    1. Highlights critical factors influencing loan approval decisions.

Technologies Used:
1. Python: Core programming language for building the pipeline.

2. Pandas: For data manipulation and preprocessing.

3. Scikit-learn: For machine learning model development and evaluation.

4. Plotly: For creating interactive visualizations and exploratory data analysis (EDA).

How It Works:

1. Data Preparation:

    1. Loads and preprocesses loan data, addressing missing values and encoding categorical variables.

2. Exploratory Data Analysis:

    1. Generates interactive visualizations to explore key features and relationships in the dataset.

3. Model Training:

    1. Trains machine learning models to predict loan approval status, evaluates performance using metrics like accuracy and F1-score.

4. Visualization and Insights:

    1. Provides insights into critical predictors like applicant income, credit history, and loan amount.
